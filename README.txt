# Suraj Motorsport Photography Portfolio

## Quick start
1. Open `index.html` in a web browser.
2. Replace the placeholder images in `images/` with your own photos.
3. Keep the same filenames:
   - `hero.jpg`
   - `photo-01.jpg`
   - `photo-02.jpg`
   - `photo-03.jpg`
   - `photo-04.jpg`
   - `photo-05.jpg`
4. Update your email and social links in `index.html`.

## Recommended image sizes
- Hero: 2400px wide or larger
- Gallery: 1600–2400px on the long edge
- Export as JPEG, around 75–85% quality, to keep the site fast.

## Customization
- Main styling: `styles.css`
- Page content: `index.html`
- Lightbox behavior: `script.js`

The site is fully responsive and works on desktop and mobile.
